图片压缩原理

本工具使用浏览器 Canvas API 对图片进行重新编码。JPG/WebP 为有损压缩：通过降低色彩精度和采样率减小文件体积，质量参数越低体积越小、画质损失越明显；PNG 为无损格式，选择 PNG 输出体积变化不大。推荐设置：照片类用 JPG 质量 70–85，图标/截图用 WebP 质量 80–90，透明背景用 PNG。

为什么要压缩图片？

①网站加载更快：图片占网页体积 60% 以上，压缩后首屏加载时间可缩短 50%；②节省存储和流量：手机流量宝贵，压缩图片减少用户流量消耗；③SEO 友好：Google 和百度都将页面加载速度作为排名因素，压缩图片直接提升 Core Web Vitals 评分；④上传限制：很多平台（微信、报名系统、邮件）对图片大小有限制。

常见问题

图片会上传到服务器吗？隐私安全吗？

不会。所有压缩操作在你的浏览器本地完成，图片不会上传到任何服务器。处理完关闭页面后图片数据即被清除，隐私安全有保障。

压缩质量设多少最合适？

一般用途设70–85：照片发朋友圈/微博设70–80，网站展示设80–85，印刷用设90以上。质量低于60会出现明显马赛克，高于90体积急剧增大但画质提升有限。建议边调边看预览。

JPG、PNG、WebP 选哪个？

照片/复杂图像选JPG或WebP（体积小）；图标/截图/透明背景选PNG（无损、支持透明）；WebP兼顾体积和画质，比JPG小25%–35%，但旧版浏览器不支持。目前主流浏览器均支持WebP。

支持批量压缩吗？

当前版本支持单张图片压缩。如需批量处理，可使用图片处理软件（如XnConvert、RIOT）或命令行工具（ImageMagick）。本工具的优势是免安装、打开即用、隐私安全。

压缩后图片画质会明显下降吗？

质量80以上肉眼几乎看不出差异，质量60–80有轻微损失但不影响使用，质量60以下会出现明显色块和模糊。建议压缩前后对比预览，在可接受画质下取最低质量以获得最小体积。

常见问题

图片会被上传到服务器吗？

不会。压缩完全在浏览器本地用 Canvas 处理，图片不会离开你的设备，断网也能使用。

压缩后画质会明显变差吗？

会有损失，程度取决于质量参数。质量值越低，体积越小、细节丢失越明显；日常使用建议在 0.6 到 0.8 之间取平衡，证件照等场景建议更高质量。

支持哪些图片格式？

浏览器能解码的常见格式都可以读取，包括 JPEG、PNG、WebP；输出通常为 JPEG 或 WebP，体积明显小于原图。
